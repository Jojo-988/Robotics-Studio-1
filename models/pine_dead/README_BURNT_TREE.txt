Burnt pine tree model for Gazebo. Original DAE geometry retained. Bark texture charred; foliage restored from backup and recoloured burnt copper-brown, with irregular thinning. model.sdf displays both Bark and Branch submeshes. Gazebo Classic uses OGRE material script; Gazebo Sim may use PBR albedo. If your Gazebo version ignores submesh names or transparency, import DAE in Blender and apply materials explicitly. Restart Gazebo after replacing the model.
